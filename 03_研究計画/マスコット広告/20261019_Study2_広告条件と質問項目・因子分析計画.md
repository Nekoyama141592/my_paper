# Study 2：不服従広告の印象項目と因子分析計画

作成日：2026年10月19日
段階：実査前の質問項目候補。検証済み尺度ではなく、Study 1の自由記述と予備確認を踏まえて確定する。

## 1. 目的とStudy 1との関係

Study 1は、刺激性／誠実性のブランド像によって、不服従広告と従順広告のブランド態度への効果差が異なるかを検証する。Study 2は、不服従広告がどのような印象として受け取られ、その印象がブランド態度とどう関連するかを探索する。

Study 2で同時点に測定する印象とブランド態度の関連から、因果的な媒介過程は確定しない。Study 1で効果が確認できなかった場合も、「確認された効果の理由」ではなく、印象構造とブランド態度との関連を調べる研究として位置づける。

## 2. 対象とする広告

宣伝部がコピーA「今日のおやつに、ポッケ。」を指定したのに対し、ぽっけくんがコピーB「おやつの時間だ、ポッケ。」を採用する不服従広告を共通に使う。広告下半分に小さなぽっけくんを追加した版を使用する。

| 条件 | 最初に提示するカード | 続いて提示する広告 |
|---|---|---|
| ① | 刺激性を強調するブランド紹介 | 不服従広告：A指定→B採用 |
| ② | 誠実性を強調するブランド紹介 | 同じ不服従広告：A指定→B採用 |

参加者はどちらか一方に無作為に割り付け、一人に一つの組み合わせだけを提示する。この設計は不服従広告の印象構造を対象とし、不服従と従順の差を再検証するものではない。Study 2でもその差を検証する場合は、Study 1と同じ4条件が必要になる。

採用コピーは全参加者で共通である。ただし、不服従広告一枚だけの結果であるため、他のコピーや商品、キャラクターへの一般化には限界がある。

## 3. 印象項目の候補（18項目）

質問文：「広告を見て、以下の内容をどの程度感じましたか」

回答：1「まったくそう思わない」〜7「非常にそう思う」。

以下の観点は項目を考えるための整理であり、6因子を採用すると決めたものではない。回答者に観点名は示さず、項目順はランダム化するなど、同じ観点の項目が連続する影響を抑える。

| 番号 | 仮の観点 | 質問項目 |
|---|---|---|
| 1 | 自分の意思を持つ感じ | ぽっけくんは、自分なりの考えを持っているように感じる。 |
| 2 | 同上 | ぽっけくんは、自分の意思で行動しているように感じる。 |
| 3 | 同上 | ぽっけくんは、言われたことを伝えるだけの存在ではないと感じる。 |
| 4 | 親しみやすさ | ぽっけくんを身近に感じる。 |
| 5 | 同上 | ぽっけくんには、気軽に話しかけられそうだ。 |
| 6 | 同上 | ぽっけくんには、気取らない雰囲気がある。 |
| 7 | 面白さ | ぽっけくんの言動は面白い。 |
| 8 | 同上 | この広告には、思わず笑ってしまうところがある。 |
| 9 | 同上 | この広告は、娯楽として楽しめる。 |
| 10 | 演出への違和感 | ぽっけくんの言動は、わざとらしく感じる。 |
| 11 | 同上 | ぽっけくんの個性が、無理に作られているように感じる。 |
| 12 | 同上 | この広告は、意外性を狙いすぎていると感じる。 |
| 13 | 振る舞いの不適切さ | ぽっけくんの振る舞いは、企業の広告にふさわしくないと感じる。 |
| 14 | 同上 | ぽっけくんの言動には、礼儀が欠けていると感じる。 |
| 15 | 同上 | ぽっけくんの行動には、無責任さを感じる。 |
| 16 | ブランドとの適合感 | ぽっけくんの振る舞いは、ポッケらしいと感じる。 |
| 17 | 同上 | ぽっけくんの言動は、紹介されたブランドのイメージに合っている。 |
| 18 | 同上 | この広告でのぽっけくんの振る舞いは、ポッケに期待するものと一致している。 |

ブランドとの適合感は、不服従が刺激性ブランドでは「このブランドらしい」、誠実性ブランドでは「紹介されたイメージと合わない」と受け取られる可能性を捉えるための候補である。この差や因子の成立は未検証である。

以前の候補にあった「消費者の味方」「利用者のために行動している」は、現在の広告がコピー変更の理由を消費者の利益として描いていないため、今回の候補から外す。自由記述で該当する印象が挙がれば再検討する。

## 4. 質問項目を確定する手順

1. Study 1の自由記述から、回答者自身が述べた印象を抽出する。
2. 上記候補と合わせ、内容の重複や理解しにくい表現を点検する。
3. 「率直」「正直」「子どもっぽい」など重要な印象が出た場合は、関連する項目を複数用意し、優先度の低い項目と入れ替える。
4. 少人数の認知インタビュー等で、意図した意味に理解されるか確認する。
5. 内容を十分にカバーしつつ15〜20項目程度に絞る。

想定した6つの観点を維持するために項目を選ばない。同義語だけで項目数を増やさず、広告全体への評価とキャラクターへの印象の対象の違いにも注意する。項目3は否定を含むため理解しやすさを確認する。また、意思の知覚が不服従の操作チェックと重複しすぎないかを点検する。

## 5. 因子分析に含めない質問

### ブランド態度

Study 1と同じ主要結果指標として、以下の3項目を別に測定する。いずれも7件法。現行の日本語項目案であり、実査前に既存尺度との内容対応を確認する。

1. このブランドに好感を持つ。
2. このブランドが好きだ。
3. このブランドに良い印象を持つ。

### 操作チェック

「このキャラクターは、会社の指示に逆らっていると感じる。」を7件法で測定する。全員に不服従広告を見せるStudy 2では、従順条件との操作差を検定できない。知覚の分布を確認する目的で用い、低得点を理由に事後的に参加者を除外しない。

### その他

表示不具合、注意の確認、必要な属性項目は因子分析に含めない。

提示順の案は、ブランド紹介→広告→ブランド態度→印象項目→操作チェック・品質確認→属性とする。Study 1の自由記述収集と、Study 2の定量的な印象測定を区別する。

## 6. 因子分析と回帰分析

印象項目だけを対象に探索的因子分析を行い、項目のまとまりから因子を命名する。「親しみ」と「面白さ」が同じ因子になる場合なども想定し、因子数を6に固定しない。

- 相関行列、KMO、Bartlett検定などから因子分析の適用可能性を確認する。
- 主因子法または最尤法などの共通因子モデルを用い、主成分分析と区別する。
- 因子間に相関があることを想定し、斜交回転を用いる。
- 平行分析、スクリープロット、内容の解釈可能性を踏まえて因子数を判断する。
- 低い因子負荷、交差負荷、共通性、内容の重複を確認する。項目削除の数値基準は実査前に確定する。
- 最終的な因子負荷表、削除項目と理由、因子間相関、各因子の内的一貫性を報告する。

次に、因子得点または妥当な尺度平均とブランド態度の関連を、ブランド紹介条件を考慮した回帰分析で検討する。

`ブランド態度 = ブランド紹介条件 + 因子1 + 因子2 + … + 誤差`

因子数と名称は分析結果に基づく。多重共線性、係数と信頼区間、モデルの説明力を確認する。同じ標本で因子発見と回帰を行う場合は、一連の分析を探索的と明記する。因子とブランド態度の相関・回帰係数を因果効果とは呼ばない。

## 7. 二条件をまとめて分析するときの注意

二つの紹介条件をまとめた因子分析では、条件間の平均差そのものが項目間の共変動を生む可能性がある。条件別の分布や相関を確認し、十分な標本を確保できる場合は因子構造の共通性を点検する。

後続の回帰にブランド条件を入れるだけでは、因子構造が条件間で共通であることは保証されない。構造が大きく異なる場合は、一つの共通尺度として解釈することを再検討する。因子得点の条件間平均比較を行う場合にも、測定の比較可能性を別途確認する。

標本数は18項目という数だけで決めず、負荷量、因子数、条件別の構造確認に必要な人数を踏まえて設計する。総数150〜200人という従来の初期目安があっても、それを二分した各群で安定した構造確認ができるとは限らない。募集数と分析の範囲は実査前に確定する。
