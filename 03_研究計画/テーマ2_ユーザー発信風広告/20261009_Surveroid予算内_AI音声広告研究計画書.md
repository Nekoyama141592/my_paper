# Surveroid予算内で行うAI音声広告研究計画書

作成日: 2026年10月9日  
予算上限: 25,000円（税込）

## 1. 研究計画の結論

本研究では、**事実中心のユーザー発信風動画広告において、AI音声と人間音声が広告信頼性に及ぼす効果を比較する2条件の被験者間実験**を行う。

予算内で標本数と検証力を確保するため、探索的因子分析用の別調査や2×2の4条件実験は本研究の中心にしない。先行研究で使われた既存尺度を利用し、AI音声が持つ次の2つの競合する心理経路を検証する。

`AI音声／人間音声 → 処理流暢性・知覚された人間らしさ → 広告信頼性 → 購買意向`

- 正の経路: AI音声は、事実情報を整理して淡々と伝えるため、情報を処理しやすく感じさせる可能性がある。
- 負の経路: AI音声は、人間らしさや温かさを低く感じさせ、信頼性を下げる可能性がある。
- 総合効果: 2つの経路の強さによって、AI音声が人間音声を上回る場合、下回る場合、差が相殺される場合がある。

この設計で明らかにできるのは、**AI音声の一般的な優位性ではなく、事実中心のUGC風広告という条件における相対的な有効性と、その心理的理由**である。

## 2. 仮タイトル

**事実中心のユーザー発信風動画広告におけるAI音声の効果――処理流暢性と知覚された人間らしさが広告信頼性に及ぼす影響――**

## 3. 研究目的と意義

### 3.1 研究目的

1. 事実中心のUGC風動画広告において、AI音声と人間音声で広告信頼性に差が生じるかを調べる。
2. AI音声が処理流暢性を高める一方、人間らしさや温かさを低下させるかを調べる。
3. これらの競合する心理経路が広告信頼性、さらに購買意向とどのように関係するかを調べる。

### 3.2 学術的意義

AI音声を単純に「人間音声より良い／悪い」と評価せず、処理しやすさという利点と、人間らしさの低下という不利が同時に生じるモデルとして検討できる。

### 3.3 実務的意義

企業がAI音声を採用すべきかだけでなく、AI音声が適する広告内容と、制作時に補うべき弱点を示せる。たとえば、処理流暢性の利点が確認され、人間らしさの低下も確認された場合、AI音声は事実説明には利用しやすいが、自然さや温かさを補う必要があると提案できる。

## 4. Research Questions

- **RQ1**: 事実中心のUGC風動画広告において、AI音声と人間音声では広告信頼性に違いが生じるか。
- **RQ2**: 音声タイプの効果は、処理流暢性と知覚された人間らしさという競合する心理経路によって説明されるか。
- **RQ3**: 広告信頼性は購買意向とどのように関係するか。

## 5. 仮説

- **H1**: 事実中心の広告では、AI音声条件は人間音声条件より処理流暢性が高い。
- **H2**: 人間音声条件はAI音声条件より知覚された人間らしさ・温かさが高い。
- **H3**: 処理流暢性が高いほど、広告信頼性は高い。
- **H4**: 知覚された人間らしさ・温かさが高いほど、広告信頼性は高い。
- **H5**: 広告信頼性が高いほど、購買意向は高い。
- **H6a**: AI音声は、処理流暢性を介して広告信頼性に正の間接効果を持つ。
- **H6b**: AI音声は、人間らしさ・温かさの低下を介して広告信頼性に負の間接効果を持つ。

H6aとH6bの媒介分析は、媒介変数と結果変数を同じ調査時点で測定するため、因果関係の確定ではなく**探索的な関連モデル**として扱う。

## 6. 実験デザイン

### 6.1 基本設計

| 項目 | 内容 |
|---|---|
| デザイン | 2条件の被験者間実験 |
| 条件1 | AI音声による事実中心のUGC風広告 |
| 条件2 | 人間音声による事実中心のUGC風広告 |
| 操作する要因 | ナレーション音声のみ |
| 主たる結果 | 広告／メッセージ信頼性 |
| 主な心理変数 | 処理流暢性、人間らしさ・温かさ |
| 副次的結果 | 購買意向、広告態度 |
| 目標標本 | 合計240名、各条件約120名 |
| 割り当て | 無作為割り当て |
| 商品 | 架空ブランドのモバイルバッテリー |

### 6.2 対象者

- 日本国内の18歳以上を基本とする。
- 短尺動画広告を現実に見る可能性のある人を対象とする。
- 年齢などで厳しい事前スクリーニングは行わない。Surveroidのスクリーニング調査を追加すると予算を超えるためである。
- 大学生だけに限定したい場合は、大学内で無料募集する方が予算上適している。

### 6.3 なぜ2×2実験にしないか

AI／人間音声×事実／体験メッセージの2×2実験は理論的には有用だが、240名でも1条件60名となり、小さい交互作用を検出しにくい。予算上限のもとでは、AI音声が比較的適すると予想される事実中心広告に絞り、1条件約120名を確保する方が堅実である。

## 7. 用意する広告素材

### 7.1 商品設定

- 架空ブランド名: `NOVA Charge`
- 商品: モバイルバッテリー
- 容量: 10,000mAh
- 重さ: 約160g
- USB-C急速充電対応
- バッテリー残量の数字表示あり

架空ブランドにすることで、実在ブランドへの既存態度や利用経験の影響を抑える。

### 7.2 共通台本案

> 持ち歩き用のモバイルバッテリーを探している人に、NOVA Chargeを紹介します。重さは約160グラム、容量は10,000mAhで、USB-Cの急速充電に対応。残量は数字で確認でき、通学や外出時にも使いやすい仕様です。

### 7.3 動画仕様

- 縦型9:16、20～30秒。
- 同一の映像、台本、字幕、BGM、長さ、商品情報を使用する。
- 両条件に同じ位置、大きさ、時間で「PR」と表示する。
- 条件間で変えるのはナレーション音声だけにする。
- 商品、カット数、商品が映る時間、文字量、アカウント情報を揃える。
- AIであることは回答前に開示せず、調査終了後に説明する。これにより、AI利用の開示効果ではなく音声表現自体の効果を測る。

### 7.4 音声の統制

- AI音声と人間音声の知覚性別、知覚年齢、声の高さ、話速を近づける。
- 読み上げ時間、音量、ラウドネス、ノイズ、残響、圧縮品質を揃える。
- 人間音声だけに強い感情や息づかいが残らないようにする。
- AI音声を意図的に機械的にしない。
- AI音声サービス、音声名、設定、生成日、編集手順を記録する。
- 人間話者から研究利用の許諾を得る。無断の音声クローンは使用しない。

## 8. 予備調査

本調査前に、大学内や知人募集などの無料標本30～50名で実施する。Surveroidは本調査だけに利用する。

### 8.1 確認項目

すべて7件法を基本とする。

- この音声は自然だった。
- この音声は聞き取りやすかった。
- 話す速さは適切だった。
- 声の高さは適切だった。
- 音量は適切だった。
- 音声と映像が合っていた。
- この声に好感を持った。
- この音声はAIによる合成音声だと思った。
- この音声は人間らしいと感じた。

### 8.2 素材採用の判断

- 自然さ、聞き取りやすさ、話速、声の高さ、音量、映像との適合に極端な差がある場合は作り直す。
- AI／人間らしさの認識だけが異なり、基本的な音声品質は大きく異ならない組み合わせを目指す。
- 本調査では、AI音声をAIと見抜けなかったことだけを理由に参加者を除外しない。

## 9. 本調査の質問項目案

原則として、`1＝全くそう思わない～7＝非常にそう思う`の7件法を使う。以下は設計用の日本語案であり、本調査前に原典を確認し、翻訳・逆翻訳、指導教員による内容確認を行う。

### 9.1 処理流暢性：4項目

1. この広告の内容は理解しやすかった。
2. この広告の情報は頭に入りやすかった。
3. この広告の説明は整理されていた。
4. この広告の内容は一貫していた。

### 9.2 知覚された人間らしさ・温かさ：3項目

7件の両極尺度を使用する。

1. 機械的である ― 人間らしい
2. 冷たい ― 温かい
3. 人工的である ― 自然である

「自然さ」は刺激品質とも重なるため、予備調査結果と尺度原典を踏まえて最終項目を調整する。

### 9.3 広告／メッセージ信頼性：3項目

1. この広告が伝える情報は正確だと思う。
2. この広告が伝える情報は真正であると感じる。
3. この広告が伝える情報は信じられる。

これは主たる結果変数であり、Appelman and Sundar（2016）のメッセージ信頼性尺度を基礎とする。

### 9.4 購買意向：3項目

1. この商品を購入してみたい。
2. モバイルバッテリーが必要になったら、この商品を候補に入れたい。
3. この商品についてさらに詳しく調べたい。

### 9.5 広告態度：3項目

1. この広告に好感を持った。
2. この広告は良い広告だと思う。
3. この広告を好ましく感じた。

### 9.6 操作・品質確認：4項目

1. この音声はAIによる合成音声だと思った。
2. この音声は自然だった。
3. この音声は聞き取りやすかった。
4. 音声と映像が合っていた。

### 9.7 注意確認

広告内で紹介された商品の特徴を1問尋ねる。例として、バッテリー容量を選択式で回答してもらう。

### 9.8 最小限の属性・探索項目

- 年齢
- 性別（回答しない選択肢を含む）
- 短尺動画の視聴頻度
- AI読み上げ音声を聞く頻度
- モバイルバッテリーの所有有無

予算と回答負担を考え、主分析に不要な統制変数を大量に入れない。

## 10. 調査の流れ

1. 研究説明を提示し、同意を得る。
2. 回答者をAI音声条件または人間音声条件へ無作為に割り当てる。
3. 割り当てられた動画を1本だけ提示する。
4. 処理流暢性、人間らしさ・温かさを測定する。
5. 広告信頼性、購買意向、広告態度を測定する。
6. 音声の操作・品質確認を行う。
7. 注意確認と最小限の属性項目を尋ねる。
8. 架空広告であること、AI音声を使用したこと、研究目的を説明する。

結果変数より前に「AI音声だと思ったか」を尋ねると研究目的に気づかせるため、操作チェックは結果尺度の後に置く。

## 11. 分析計画

### 11.1 事前に固定する事項

- 主仮説と主たる結果変数
- 目標標本数と停止基準
- 除外基準
- 尺度得点の計算方法
- 主分析と探索的分析の区分

可能であれば、データ収集前にOSFなどへ事前登録する。

### 11.2 データの除外

- 同意しなかった回答
- 調査を完了していない回答
- 動画視聴や質問回答が不可能と判断できる異常に短い回答
- 事前に定めた注意確認に失敗した回答

除外基準は結果を見てから変更しない。AI音声を正しく判別できなかった回答者は、主分析から除外しない。必要なら判別できた回答者だけの結果を感度分析として示す。

### 11.3 尺度の確認

1. 各尺度の欠測、分布、平均、標準偏差を確認する。
2. 処理流暢性、広告信頼性、購買意向、広告態度についてωまたはαを報告する。
3. 標本数と使用ソフトが許せば、既存尺度の測定構造を確認的因子分析で確認する。
4. CFAが難しい場合は、探索的な構造確認であることを明記する。

本研究では既存尺度を用いるため、新しい心理因子を発見する探索的因子分析を主目的とはしない。

### 11.4 主分析

- 音声条件を説明変数、広告信頼性を結果変数とした独立標本t検定または単回帰分析を行う。
- 条件ごとの人数、平均、標準偏差、Cohen's d、95%信頼区間、正確なp値を報告する。
- H1とH2は、処理流暢性および人間らしさ・温かさを結果変数とした条件比較で検証する。
- H3～H5は回帰分析で検証する。
- H6a、H6bはブートストラップ信頼区間を用いた競合媒介モデルとして探索的に検討する。

自然さや聞き取りやすさに条件差が残った場合、それらを共変量に入れた分析を補助的に示す。ただし、共変量による統計的調整だけで刺激の交絡が解消したとは主張しない。

### 11.5 因子分析を追加する条件

無料で本調査とは別の回答者を少なくとも150名、できれば180名以上集められる場合に限り、自由記述から18～24項目程度の印象項目を作り、別Studyとして探索的因子分析を追加する。

その場合は、KMO、Bartlett検定、平行分析、最尤法または主因子法、プロマックスまたはオブリミン回転、負荷量・共通性・交差負荷、ωまたはαを報告する。本調査240名だけで、項目を探索して同じ標本で強い媒介結論まで出すことは避ける。

## 13. Surveroidで実施する前に確認すること

公式ヘルプでは設問順のランダマイズと回答による分岐は確認できるが、1つの調査内で回答者を2条件へ排他的に無作為割り当てし、異なる動画を1本だけ見せられるかは、事前に運営へ確認する。

問い合わせ文例:

> 1つの国内本調査内で、回答者をAI音声条件と人間音声条件へランダムに割り付け、異なる動画を1本だけ提示できますか。各回答者には割り当てられた動画だけを表示し、条件ごとの回収数をおおむね均等にしたいです。

もし1調査内で無作為割り当てができない場合は、回答者自身に条件を選ばせたり、回答内容で擬似的に分けたりしない。次の順に代替策を検討する。

1. 外部の無作為割り当て可能なアンケート画面から動画条件を提示し、Surveroidで募集できるか確認する。
2. 大学の調査環境や無料アンケートサービスで無作為割り当てし、学内標本を集める。
3. 予算を増やせる場合のみ、条件ごとに別調査を作る。

別々のSurveroid調査を2本作ると、最低料金だけでも合計33,000円（税込）となるため、現予算では採用しない。

## 14. 想定される結果と結論の書き方

### 14.1 AI音声の信頼性が高かった場合

「事実中心のUGC風広告では、AI音声が人間音声より高い広告信頼性をもたらした」と結論づけられる。処理流暢性を介した正の間接経路も確認された場合、AI音声の整理された情報提示が理由の一つである可能性を示せる。

ただし、「広告全般でAI音声が人間音声より優れている」とは主張しない。

### 14.2 有意差がなかった場合

AI音声が処理流暢性を高める一方、人間らしさを下げ、正負の経路が相殺された可能性を検討する。ただし、有意差がないことだけで両音声が同等とは言えない。同等性を主張するには、事前に同等性マージンを設定した同等性検定が必要である。

### 14.3 人間音声の信頼性が高かった場合

AI音声の優位性は支持されない。人間らしさや温かさの不足による不利が、処理流暢性の利点より大きかった可能性を検討する。

### 14.4 最も現実的に予想される結論

AI音声は処理流暢性を高める一方、人間らしさや温かさを低下させ、広告信頼性に対する総合効果は小さい、または条件間で明確な差が出ない可能性がある。この結果でも、AI音声と人間音声が異なる心理経路を通じて評価されることを示せれば、研究上の意味がある。

## 18. 最終推奨

本研究では、次の組み合わせを採用する。

- 事実中心のUGC風広告
- AI音声対人間音声の2条件
- 架空のモバイルバッテリー
- 広告信頼性を主たる結果とする
- 処理流暢性と人間らしさ・温かさを競合メカニズムとして測る
- 無料予備調査30～50名
- Surveroid本調査240名、6課金設問以内、23,760円（税込）
- 7課金設問になった場合は210名、24,255円（税込）
- 既存尺度を使い、探索的因子分析は無料の別標本を十分に確保できる場合のみ追加する

この設計が、25,000円以内で研究目的、内的妥当性、標本数、卒論としての実行可能性を最もバランスよく満たす。
