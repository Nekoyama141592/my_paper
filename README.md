## フォルダ構成

```text
.
├── 01_参考資料                     # 関連文献・レビュー・先輩卒論・執筆と分析の参考資料
├── 02_テーマ検討
│   └── D_詳細化                    # 不服従マスコット研究のテーマ案
├── 03_研究計画
│   └── マスコット広告              # Study1・Study2・プレ調査・刺激画像・キャラクター
├── 04_発表資料
│   ├── デジタル庁スタイル          # デザイン仕様・中間発表資料
│   └── POPスタイル                 # デザイン仕様
└── 05_卒論本文
    └── マスコット                  # 卒論草案
```

## 資料の扱い

- テーマ案には旧案・検討履歴が含まれます。現行の研究内容は卒論草案と研究計画を確認してください。
- 共通の参考資料は、研究テーマの異なる先輩卒論や参考原稿も含めて保持しています。
- 日付を付したファイル名の先頭8桁は作成日（`YYYYMMDD`）です。
- 発表資料と刺激画像の各版は、比較・検討履歴として保持しています。

## Git管理

論文、研究メモ、PDF、発表画像を追跡します。OSやアプリが自動生成する一時ファイルは `.gitignore` で除外します。
