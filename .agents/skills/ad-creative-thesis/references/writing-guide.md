# 論文執筆ガイド

章立て、本文執筆、推敲、結果報告、引用の確認に使用する。先輩の文章を写すのではなく、問いから結論までの論理と提示方法を参考にする。

## 先輩に合わせる執筆方針

本ガイドでは、今川・古賀・福田の卒論を主な文体・構成の手本とする。模倣するのは、引用の置き方、説明の順序、段落のつなぎ、見出しの階層、調査概要・結果・補録の役割である。文章そのものや固有の主張を転用しない。大学・ゼミの指定と既存稿の確定表記を優先する。

| ユーザーの指定範囲 | 手本とする箇所（PDF先頭からの頁） | 適用箇所 |
|---|---|---|
| 0．先行研究の引用・言い回し・章立て・Study間の接続 | 今川7・9・23頁、古賀2〜3・25頁、福田21頁 | 本ガイド2・3・8節 |
| 1．「である」調、RQ・仮説の提示 | 今川9頁、古賀25頁、福田21頁 | 3・4節 |
| 2．調査概要表、図表番号・出典、補録 | 今川10・16頁、古賀3頁、福田23頁 | 5節 |
| 3．結果・考察の分離 | 今川16〜17頁、古賀2頁の節構成 | 6節 |
| 4．まとめ・限界・今後の課題 | 今川29〜30頁、古賀35〜36頁 | 7節 |

以下の文章型は、原文の引用ではなく、確認した構成を基に作った執筆用の例である。角括弧内を確認済みの内容に置き換え、不要な文は省く。観測されていない結果をテンプレートに合わせて補わない。先輩に見られる強い因果表現や統計表記の誤りは引き継がない。

## 1．書く前に主張と根拠を対応させる

| 主張の種類 | 必要な根拠 | 作業時の確認状態 |
|---|---|---|
| 市場・社会の背景 | 公的資料、一次資料、確認可能な事例 | 確認済み／要確認 |
| 既存の知見 | 原著論文 | 原典確認済み／原典未確認 |
| 未解明の点 | 関連文献の比較と調査範囲 | 根拠あり／暫定 |
| 仮説 | 理論と比較条件から導く論理 | 設定済み／要検討 |
| 本研究の結果 | 実際のデータと分析出力 | 検証結果／探索的結果／未分析 |

研究上の不足は、単に「この組み合わせの研究がない」とせず、既存研究では答えられない問いを示す。先行研究が述べる範囲を超えた主張に出典を付けない。

## 2．基本の章構成

大学・ゼミの指定と確定済みの構成を優先する。指定がなければ次を基本とする。

1. **第1章 はじめに**：研究背景、研究意義、問題提起と研究課題。身近な広告事例から問いへ絞り込み、学術的意義と実務的意義を区別する。
2. **第2章 既存研究**：主要概念、主題別の知見、既存研究のまとめ、未解明の点と本研究の位置づけ。文献ごとの要約を並べるだけにしない。
3. **第3章 研究1**：目的、仮説設定、商材・広告刺激の選定、調査方法、調査概要、結果、考察。主たる成果指標の条件比較を軸にする。
4. **第4章 研究2**：研究1を受けた目的、項目生成、調査方法、因子分析、因子の解釈と信頼性、成果指標との関連分析、考察。
5. **第5章 おわりに**：研究のまとめ、研究課題への回答、学術的・実務的示唆、限界と今後の課題。
6. **参考文献・補録**：引用した資料、調査票、刺激、詳細な分析結果。完成稿では表紙と目次を整え、謝辞は実際の協力関係とユーザーの意向に基づいて記す。

見出しは `第1章 はじめに` → `1．研究背景` → `（1）学術的意義` のように統一する。本ガイドの説明中では「研究1」「研究2」と記すが、新規本文では先輩に合わせて「Study1」「Study2」を基本表記とする。既存稿で「研究1」等に統一済みなら維持する。改称する場合は本文・目次・図表・補録までそろえる。

先輩には複数研究を一つの「検証」章にまとめた例もある。五章構成を一律の提出規定としない。研究計画や一部章の依頼では必要な範囲だけ作る。本文量は提出要件と論証に必要な内容から決め、先輩の文字数へ合わせるために水増ししない。

研究2の章頭では、研究1で分かったことと残った問いを述べる。条件差が確認できなければ、印象構造と成果指標の関連を探索する目的として説明する。同一データの分析段階を別の調査のように記載しない。

### Study間をつなぐ文章型

今川23頁・古賀25頁・福田21頁にある「前の研究の主要結果 → 次の研究の目的 → RQ2 → 方法の見通し」の順を踏襲する。Study1の考察末尾とStudy2の章頭を対応させ、同じ長い説明を繰り返さない。

- **Study1の考察末尾**：「以上より、[対象場面]では[確認された差・関連]が示された。一方、[未検討の印象・条件]については明らかでない。そこでStudy2では、[残る問い]を検討する。」
- **差が確認された場合のStudy2章頭**：「Study1では、[A条件]は[B条件]と比較して[成果指標]が[方向]であることが示された。そこでStudy2では、[広告表現]から生じる印象の構造と、各印象と[成果指標]との関連を検討する。これを踏まえ、以下のRQ2を設定する。」
- **差が確認されなかった場合の章頭**：「Study1では、[条件間]の[成果指標]に統計的に有意な差は確認されなかった。一方、この結果だけでは、[広告表現]がどのような印象として受け取られ、各印象が[成果指標]とどのように関連するかは分からない。そこでStudy2では、これらを探索的に検討する。」
- **RQの後の方法説明**：「まず、[実際に用いた自由記述等]から印象項目を整理する。次に、探索的因子分析により印象の構造を検討する。最後に、[成果指標]を従属変数とする回帰分析により各因子との関連を検討する。」実施済みなら過去形にする。

新たに設定するRQは「設定する」、序論で提示済みの同一RQは「改めて提示する」とする。前の結果を見て問いを変更した場合は、その変更と探索的な性質を説明する。「再設定」を単なる再掲と混同しない。因子分析と回帰だけの研究を「心理メカニズムを証明する」と説明しない。

## 3．本文の文体と段落

本文は「である」調とし、研究主体は「本研究」とする。説明は段落でつなぎ、作業用の箇条書きや根拠一覧をそのまま完成稿に残さない。研究課題、仮説、条件、質問項目は番号や図表で示してよい。

一つの段落では、主張、根拠、本研究の文脈での解釈、次の問いへの接続を必要な順に説明する。「以上を踏まえ」「一方で」「そこで本研究では」は実際の論理関係に合わせて使う。章頭では目的、章末では要点と次章への接続を短く示す。

専門用語は初出で定義し、本文、質問票、図表、分析で名称をそろえる。信頼、信憑性、真正性などを意味の確認なしに言い換えない。未実施の方法は「検証する」「実施予定である」、実施済みの方法は「実施した」とし、予定と結果を混同しない。

### 先輩に寄せる言い回し

| 段落の役割 | 文章型 |
|---|---|
| 章の導入 | 「本章では、[主要概念]に関する既存研究を整理し、本研究の位置づけを示す。」 |
| 研究の紹介 | 「[著者]（[年]）は、[対象・方法]により、[確認された知見]を示した。」 |
| 知見の接続 | 「また、[著者]（[年]）は、[補足的な知見]を報告している。」 |
| 未解明の点 | 「一方、これらの研究では[対象・条件]については十分に検討されていない。」根拠となる調査範囲を確認する。 |
| 本研究への接続 | 「以上を踏まえ、本研究では[問い]に着目する。」 |
| 方法への導入 | 「本調査に先立ち、[商材・刺激]の選定を行った。」実際に選定した場合に限る。 |

本文では「〜です・ます」「〜だと思う」「すごく」を避け、「〜である」「〜と考えられる」「〜が示唆される」を根拠の強さに合わせて使う。「明らかになった」を段落ごとの決まり文句にせず、観測結果には「確認された」、解釈には「可能性がある」などを用いる。

## 4．研究課題と仮説

新規本文では初出を「リサーチ・クエスチョン（以下、RQ）」とし、研究課題は `RQ1：〜か。`、仮説は `仮説1-1：A条件はB条件よりも、Yが高い。` のように本文から独立して示す。記号は実際の条件名・指標名に置き換える。研究課題を略号で示す場合は、初出で説明し、全体で統一する。

仮説の前に、既存研究の知見と比較条件の違いを説明し、予測される方向へ論理をつなぐ。独立変数、比較条件、従属変数、方向、必要な対象場面が読み取れるようにする。交互作用は「どの条件で効果がどう変わるか」、媒介は想定する経路を具体的に記す。

今川9頁のように「当該Studyの目的・RQの再掲 → 既存研究からの予測 → 仮説文」の順で置く。たとえば、「[既存研究の知見]から、[AとBの違い]によって[成果指標]が[方向]になると予測される。以上を踏まえ、以下の仮説を設定する。」と説明してから、仮説を独立した行・段落で示す。方向を予測する根拠がない探索的な問いはRQとして示し、形式を合わせるためだけに仮説を作らない。

因子分析で事後的に発見した因子と同じ標本で検討した関連を、事前仮説へ書き換えない。独立した後続調査で仮説を検証する場合は、仮説設定の時点と検証用データを明示する。

## 5．方法と図表

方法は、読者が何をどの順序で行った研究かを再構成できるように記す。

- 実験条件、割り付け、募集方法、対象者、回答数、除外基準、分析対象数、条件別人数。
- 商材・刺激の選定理由、入手・作成方法、統制した要素、生成素材の使用と編集手順。
- 参加者への説明、刺激の提示、質問への回答の順序。
- 尺度の出典、翻訳・修正内容、質問項目数、回答段階と両端、得点の集約方法、信頼性。
- 研究1の主たる成果指標、操作確認、品質確認、研究2に用いた自由記述。
- 研究2の項目生成、候補の整理、提示項目と最終採用項目、因子分析の方法、関連分析の方法。
- 欠測・除外の扱い、事前計画からの変更、使用した分析ソフト。

先輩の「調査概要」表を参考に、調査期間、対象者、募集方法、回答数・除外後人数、条件別人数、実施方法、質問内容をまとめる。確認できない値は作業稿で「未定」「要確認」とし、実施したように補わない。詳しい調査票を補録に置く場合も、本文に研究の理解に必要な情報を残す。

### 調査概要表の型

今川16頁・福田23頁を手本に、左列に項目、右列に内容を置く。本文で目的・手順を説明した後、「調査概要は図表3-1に示す。」と導く。以下は未記入の型であり、実際の章番号・調査内容に合わせる。

**図表3-1 Study1 本調査の調査概要**

| 項目 | 内容 |
|---|---|
| 調査期間 | [開始日〜終了日] |
| 調査対象 | [年齢層・対象条件] |
| 募集方法 | [募集経路・調査会社等] |
| サンプルサイズ | [回答者数]、[除外数・基準]、分析対象[人数]（条件別[人数]） |
| 実施方法 | [Webアンケート等、参加者間／参加者内計画、割付方法] |
| 質問内容 | [測定概念・項目数・回答段階] |

（出典：筆者作成）

予備調査、定性調査、本調査は実施単位に応じて表を分ける。同じ調査の再利用なら元の図表を参照し、別の調査として人数を重複計上しない。表で省略した尺度の両端・出典等は本文または質問項目表に示す。

### 図表の表記

- `図表3-1 研究1の調査概要` のように章内通し番号と具体的な題名を上に置き、本文から「図表3-1に示す」と参照する。指定があれば図と表を別番号にする。
- 下部に、自作は `（出典：筆者作成）`、自分の集計は `（出典：調査結果をもとに筆者作成）` と記す。外部資料の改変は `（出典：著者名（年）、該当頁をもとに筆者作成）` などと由来を示す。
- 条件比較は条件別人数、平均、標準偏差、検定結果、効果量を示す。因子分析は項目文、負荷量、因子名、必要な注記を示す。回帰分析は係数、不確実性、モデルの説明力を示す。
- 主要な結果は本文、長い質問票や分析の全出力は補録に置く。補録の番号・題名と本文の参照先をそろえる。

### 補録の構成と本文からの案内

古賀3頁の「調査票／分析結果」を基本に、必要に応じ刺激を加える。たとえば「補録1 調査票（Study1・Study2）」「補録2 提示刺激」「補録3 詳細な分析結果」と整理し、各資料に対応するStudy・条件・項目番号を付ける。調査票は教示、提示順、分岐、全項目、回答尺度を再現できる形で収める。

本文では「使用した質問項目と教示は補録1に、詳細な分析結果は補録3に示す。」のように番号まで指定する。主仮説の判定に必要な結果や因子負荷量表を補録にしか置かない構成は避ける。補録へ置いた元の出力と本文の整理表の数値を照合する。

## 6．結果と考察を分ける

研究1は、データの確認・除外、操作確認、成果指標の信頼性と記述統計、条件比較、仮説の判定を示す。研究2は、項目生成、因子分析の適用可能性、抽出と回転、因子数と項目削除、最終負荷量、命名と信頼性、成果指標との関連分析を示す。

各結果は、分析方法、図表への参照、差や関連の方向と大きさ、仮説の判定をつなげて記述する。「仮説1-1は支持された／支持されなかった」のように番号を対応させる。分析前は結果の記入欄を用意するだけとし、都合のよい係数や有意差を書き込まない。

有意確率の丸め表示を写して `p = .000` とせず、該当する場合は `p < .001` とする。予測と逆方向なら仮説支持とはしない。有意差がないことは、差が存在しない証明ではない。有意性と実務的な大きさを区別する。

考察では、データが直接示すこと、理論的な解釈、別の説明、一般化できる範囲を分ける。同時点の自己報告や回帰の関連をそのまま因果関係と表現しない。測定していない理由は解釈の候補として述べる。

### 同じ結果を「結果」と「考察」で書き分ける

今川16〜17頁のように「（1）調査概要」「（2）調査結果」「（3）考察」を分ける。古賀のように考察を独立した節にしてもよい。配置をそろえるために節を増やしすぎず、結果段落の途中に理由の推測を混ぜない。

- **結果の型**：「[分析方法]により[比較・関連]を検討した。結果を図表[番号]に示す。[実測値と不確実性]から、[観測された方向・差]が確認された。したがって、仮説[番号]は[支持された／支持されなかった]。」非有意なら「有意な差は確認されなかった」とする。
- **考察の型**：「この結果は、[既存研究の知見]と[整合する／異なる]。その理由として、[理論に基づく解釈]が考えられる。ただし、[未測定の代替説明・設計上の制約]を排除できないため、[断定できない範囲]には留意が必要である。」必要に応じて次のStudyへつなぐ。

結果節には観測事実と仮説判定、考察節にはその意味・先行研究との関係・別の説明を置く。先輩の「棄却された」という表現を機械的に写さず、非有意の研究仮説には原則「支持されなかった」を用いる。

## 7．まとめ・示唆・限界

研究課題ごとに、各研究の結果が何を示し、何が未解決かを答える。学術的示唆は既存研究の知見をどう補足・限定したかを示す。実務的示唆は、誰がどの状況でどの広告表現を検討できるかを、結果の範囲内で具体化する。

限界は「第一に、〜」「第二に、〜」と段落で整理し、「今回の制約 → 解釈への影響 → 今後の検証」をつなぐ。人数や商材が少ないと列挙するだけにしない。結論で新しい分析結果や未検証の効果を追加しない。

### 最終章の文章型

今川29〜30頁・古賀35〜36頁に合わせ、基本見出しを「1．本研究のまとめ」「2．本研究の限界と今後の課題」とする。学術的・実務的示唆を独立節にする必要があれば、まとめと限界の間に置く。

まとめは「研究目的の再提示 → Study1の方法と主要結果 → Study2の方法と主要結果 → 両研究を通じたRQへの回答」の順で段落を組む。各Studyの考察をそのまま再掲せず、支持されなかった仮説や関連が確認できなかった因子も、結論の範囲を決めるものとして含める。

> 本研究は、[広告表現]と[成果指標]との関係、および[印象に関する問い]を検討することを目的とした。Study1では、[比較方法]により[主要結果]が示された。一方、[確認できなかった点]も残された。続くStudy2では、[項目生成・分析方法]により[確認された構造・関連]が示された。以上より、[対象と条件を限定したRQへの回答]が得られた。

限界は先輩のように項目ごとの段落で述べ、それぞれに今後の課題を対応させる。項目数を先輩と同じにする必要はない。

> 第一に、本研究では[対象・商材・測定等の具体的制約]がある。そのため、[結論を適用できない範囲／残る代替説明]が残されている。今後は、[追加する条件・測定・標本・設計]により、[検証すべき問い]を検討する必要がある。

たとえば単一商材なら「他の商品カテゴリでも同じ結果になるか」、意向のみの測定なら「選択課題や購買データでも関連が認められるか」、同一標本の探索なら「独立標本でも因子構造・関連が再現するか」を課題にする。実際の設計に当てはまるものだけを選ぶ。「サンプルが少ない」「今後さらに研究が必要である」だけで終えない。

## 8．本文引用と参考文献

先輩の卒論に見られる著者・年方式を基本とし、末尾の見出しを「参考文献」とする。次は本プロジェクトの統一方針であり、先輩全員に共通する規則や特定学会への厳密な準拠とは扱わない。大学・ゼミやユーザーの明示的な指定があれば優先する。

### 本文引用

- 「著者名（年）は、〜を明らかにした。」「〜が示されている（著者名，年）。」の形で内容を要約する。
- 和文は姓を用い、著者1名は「山田（2020）」、2名は「山田・佐藤（2020）」、3名以上は「山田ら（2020）」とする。これらは架空の形式例であり、実在文献として引用しない。
- 欧文の著者名は原綴りを保持する。本文では1名は姓、2名は両者の姓を `&` で結び、3名以上は第一著者の姓に `et al.` を添える。年の括弧は全角に統一する。著者数・順序は原典を確認する。
- 同一著者・同一年の別文献は年の後ろに `a`、`b` を付け、本文と参考文献で一致させる。
- 一つの研究は必要に応じて、目的・対象・方法、結果、本研究との関連の順に紹介する。主題ごとに研究をつなぎ、節末で既知の点と未解明の点を整理する。
- 「示唆した」「明らかにした」は原典の証拠の強さに合わせる。著者の結果と自分の推論を混同しない。
- 直接引用にだけ引用符を付け、該当頁を示す。頁のない資料では節や段落を特定する。要約を原文の引用のように見せない。

### 既存研究を段落にまとめる型

今川7頁のように、主題ごとに著者・年を主語とする研究紹介をつなぎ、節末で知見をまとめる。次は架空の記入例であり、著者や知見は原典確認後に埋める。

> [著者A]（[年]）は、[対象・方法]により[知見A]を示した。また、[著者B]（[年]）は、[関連する条件]における[知見B]を報告している。これらの研究から、[両研究に共通する知見]が示されている。一方、[本研究が扱う条件]については[具体的に残る問い]がある。そこで本研究では、[RQにつながる対象]を検討する。

先行研究の結果を紹介する文と「本研究では〜と考える」という推論の文を分ける。「以上より」に続けて引用元が検討していない効果まで確定事項として広げない。先輩の参考文献一覧にあるだけの文献は、原典を読むまで自分の本文の根拠として扱わない。

### 末尾の参考文献

以下の角括弧は記入欄であり、完成稿では確認した情報に置き換える。

- 和文論文：`[著者全員]（[年]）「[論文名]」『[誌名]』[巻]（[号]）、[開始頁]-[終了頁]。`
- 和文書籍：`[著者全員]（[年]）『[書名]』[出版社]。`
- 欧文論文：`[著者全員の姓と名の頭文字] ([年]). “[原題].” [原綴りの誌名], [巻]([号]), [開始頁]-[終了頁].`
- 卒業論文：`[著者氏名]（[年]）「[題名]」[大学・学部・ゼミ等] 卒業論文。`
- ウェブ資料：`[著者・組織名]（[公開年]）「[ページ名]」〈[資料のURL]〉（[実際の確認年月日]閲覧）。`

本文で引用した資料と参考文献を一対一で照合する。参考文献では本文用の著者省略を引き継がず、原典の著者一覧を記す。巻号、頁、論文番号は原典にある形式で記載し、欠けた情報を推測しない。公開年が分からなければ「年不明」とする。確認できたデジタル識別子は追記してよい。

配列指定がなければ和文・欧文を分け、和文は第一著者の五十音順、欧文は第一著者姓のアルファベット順にする。原典未確認の文献は作業メモで区別し、確認済みの引用として完成稿へ入れない。先輩の参考文献に誤記があっても引き継がない。

## 10．完成前の照合

- 事実、既存研究、新規性の主張に追跡可能な根拠があるか。
- 本文引用と参考文献、著者名と年、引用箇所が一致しているか。
- 研究課題、仮説、変数名、図表、結論の対応が一貫しているか。
- 人数、条件数、質問数、除外数、因子の採用項目が本文と表で一致しているか。
- 因子分析、信頼性、得点化、回帰分析が同じ最終項目に基づいているか。
- 仮説が支持されなかった結果や探索的分析を正しく報告しているか。
- 予定、実施済みの方法、観測結果、解釈を区別できるか。
- 要約、序論、結論で述べる貢献が同じか。
- 補録に約束した刺激、質問票、詳細分析があり、参照先が一致するか。
- 完成稿に未記入欄、架空の引用・統計値、作業用メモが残っていないか。
