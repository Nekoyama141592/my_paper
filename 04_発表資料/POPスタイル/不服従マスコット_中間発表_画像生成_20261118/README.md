# 不服従マスコット研究・中間発表スライド画像

2026年11月18日作成。全14枚、PNG、1920×1080（16:9）。

- `slides/`：ページ順の完成スライド画像。
- `index.html`：ブラウザで開く一覧。画像クリックと左右キーで1枚ずつ閲覧可能。
- `prompts.json`：内蔵 image_gen に渡した共通指示と各ページの全文。CLI/APIフォールバックは不使用。
- `刺激原画像/`：現行の広告・ブランド紹介・マスコット原画像の無改変コピー。スライド画像とは別に保存。
- `source.md`：各ページの確定本文。

指定デザイン：`../DESIGN.md`（POP Academic）。内容は卒論草案の2026年11月17日更新版と現行作業メモに基づく。実査前のため結果、支持済み仮説、因子数、効果量を追加していない。

生成方法：各ページを内蔵 image_gen で個別生成し、日本語、四条件、分析計画を目視確認。配布用PNGの解像度のみ1920×1080に統一。表紙のマスコットは原画像を参照した生成表現であり、実験刺激として使用しない。7頁は「刺激文案」であり広告の原画像ではない。

スライド画像内の文字は画像として固定されている。本文を変更する際は source.md と prompts.json を参照する。
