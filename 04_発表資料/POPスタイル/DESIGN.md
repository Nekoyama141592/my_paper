# POPスタイル：不服従マスコット研究の発表デザイン

## Overview

大学の卒論・研究計画発表に用いる、親しみやすく明快なスライドのデザインシステム。白い余白、大きな日本語見出し、ネイビーの文字、シアンのアクセントを基調に、丸みのあるカードと吹き出しでPOPらしさを出す。マスコットの面白さを入口にしつつ、何を比較し、どこまで分かる研究なのかを伝える。

対象研究は「マスコットの企業への不服従表現がブランド態度に及ぼす影響――ブランド・パーソナリティに着目して――」。スライドは一枚につき一つのメッセージとする。想定読者はゼミ教員と学生であり、専門用語には短い説明を添える。

### 参照元と適用範囲

- 書式：[google-labs-code/design.md](https://github.com/google-labs-code/design.md)、[仕様本文](https://github.com/google-labs-code/design.md/blob/main/docs/spec.md)（2026-11-18確認）。数値・色・参照はYAML、使用意図と配置は本文に記述する。
- 内容：[卒論草案](../../05_卒論本文/マスコット/20261019_マスコットの企業への不服従表現_卒論草案_Study1まで.md)（2026-11-17更新版）。本文と現行の作業メモを優先し、過去の改訂履歴を現行計画として使わない。
- 本ファイルは発表用のスタイルであり、実験刺激の見た目を変更する指示ではない。掲載する刺激は草案の「現行仕様の画像ファイル」から取得する。
- 研究は実査前。Study1・Study2の結果、支持された仮説、確定因子、効果量を補作しない。草案が更新された場合は内容例も追従させる。

## Colors

| トークン | 役割 | 適用 |
|---|---|---|
| primary | 主文字・見出し | 白地または淡色カード上のネイビー |
| secondary | 説明文 | 本文の補足 |
| tertiary | アクセント | ライン、図形、矢印の装飾 |
| neutral | 背景 | 原則として全ページ白 |
| surface / surface-soft | 面の区分 | 比較表、カード、注記欄 |
| accent-soft | 注目領域 | RQ、要点帯 |
| accent-text | 強調文字 | 白地・淡色地の強調語 |
| border / muted | 補助要素 | 罫線／出典・ページ番号 |

シアン `#08A9D6` は白地の小さな文字に使わず、文字には濃い `#006B89` を使う。通常文字は背景とのコントラスト比4.5:1以上を確保する。色の役割はページ間で固定し、一枚の主役は白・ネイビー・シアンの三色に絞る。

従順／不服従を善悪の緑／赤で分けない。刺激性／誠実性も派手／地味の配色で描き分けず、同じ背景・文字色・枠線と明示ラベルで区別する。比較する広告は同じ大きさと視覚的な重みで扱う。刺激画像自体の固有色は保持する。

## Typography

フォントはNoto Sans JPを基本とし、利用できない場合はヒラギノ角ゴシック、游ゴシックの順に代替する。代替後は改行とはみ出しを再確認する。見出し・ラベルは700、本文・出典は400を基本とする。

YAMLのpx値は1600×900の基準キャンバス上の設計寸法である。PowerPointを13.333×7.5インチで作る場合は、座標を120px＝1インチ、文字を1px＝0.6ptとして換算する。本文32pxは19.2pt、タイトル48pxは28.8ptに相当する。CSSの一般的なpx→pt換算とは混同しない。

- 通常タイトルは二行以内。表紙の正式題名は意味のまとまりで二〜三行に分け、副題を別行に置く。
- 主要本文は一枚5〜7行程度。表や刺激比較が密になる場合はページを分け、文字縮小で解決しない。
- 出典は24pxを基本とし、長い書誌情報は参考文献ページへ移す。
- 日本語には「 」を使用し、句読点や閉じ括弧が行頭に来ないよう調整する。
- 画像に文字を含める場合は、原文との照合を必須とする。

## Layout

### キャンバスと余白

16:9、基準1600×900。画像出力は1920×1080など同比率へ拡大してよい。1792×1024は16:9ではないため標準サイズにしない。左右72px、上下は最低48pxの安全域を確保し、主要内容は72px内側から置く。カード間は32px、カード内余白は32pxを基本とする。

上部にタイトル、中央に主図または比較、下部に要点と出典を配置する。出典は左下、任意のページ番号は右下のみ。**右上にはページ数・スライド番号・進行表示を置かない。** 右上は主内容に必要な場合以外は余白にする。

### レイアウトの使い分け

| パターン | 構成 | 主な用途 |
|---|---|---|
| 表紙 | 左に正式題名、右に既存マスコット素材、下に発表者と日付 | テーマ提示 |
| 大きな問い | 中央の大きな問い＋下に定義 | RQ1・RQ2 |
| 二列比較 | 等幅カード二枚＋共通点の帯 | 従順／不服従の操作説明 |
| 2×2マトリクス | 行にブランド像、列に振る舞い | Study1の四条件 |
| 理論カード | 最大三列、各カードに知見・出典・今回への接続 | 先行研究 |
| 仮説と問い | 同じサイズの二カード、仮説／RQを明示 | 仮説1-1とRQ1-2 |
| 手続きフロー | 左から右に最大五段階 | 調査や分析の順序 |
| 項目の内訳 | 大きな合計数＋三つの内訳 | Study2の測定22項目 |

三列カードを全ページに繰り返さない。刺激比較では広告内の指示・発言・採用コピーが読める大きさを優先する。全体像と拡大図を分ける場合、拡大箇所を明示し、画像の内容を編集しない。

### 発表構成の標準例

枚数は発表時間に合わせる。以下は内容の順序を示す14枚の基本案であり、固定の枚数指定ではない。

| 頁 | 主題 | 伝える内容 |
|---|---|---|
| 1 | 表紙 | 正式題名、副題、発表者、日付、研究計画 |
| 2 | 背景 | 企業と異なる意思を示すマスコットという着眼点 |
| 3 | 定義とRQ1 | 明示的な指示への不服従と、ブランド像による効果差 |
| 4 | 既存研究 | 広告キャラクター、ブランド・パーソナリティ、期待から外れる振る舞い |
| 5 | 研究の位置づけ | 既存知見と今回検証する推論の区別 |
| 6 | 仮説と問い | 刺激性での正の予測、誠実性での方向を限定しない問い |
| 7 | Study1の設計 | 2×2の四条件、各参加者は一条件 |
| 8 | 刺激の比較 | 従順A指定→A採用／不服従B指定→A採用 |
| 9 | 手続きと測定 | 誕生月による割付、ブランド態度、自由記述、操作チェック |
| 10 | Study1の分析 | 交互作用と二つの計画比較、三検定のHolm調整 |
| 11 | Study2への接続 | 未解明の印象構造とブランド態度との関連、RQ2 |
| 12 | Study2の計画 | 一条件、有効回答100人予定、22項目の内訳 |
| 13 | Study2の分析 | 印象18項目の探索的因子分析、因子とブランド態度の回帰分析 |
| 14 | 意義・限界・次の作業 | 得たい知見、解釈の範囲、未確定事項 |

必要に応じて刺激紹介、尺度、参考文献を補足ページへ分ける。背景事例や文献を掲載する場合は、草案の出典と確認範囲を引き継ぐ。

## Elevation & Depth

フラットな面と余白で階層を作る。ドロップシャドウ、立体文字、グラデーションは使わない。通常カードの枠線はborder色で2px、問いや吹き出しの輪郭はprimary色で3pxを基本とする。線の太さは本文の描画ルールで指定し、仕様外のコンポーネントプロパティをYAMLへ追加しない。

## Shapes

角丸カード16px、大きな問い・吹き出し24px、要点帯8pxを使用する。吹き出しの尾は発言者へ向け、企業の指示とマスコットの発言を取り違えない。説明図には「概念図」、刺激文案の再掲には「刺激文案」と明記する。

POPらしさは丸み、大きなラベル、余白の強弱で表す。爆発形、怒りマーク、悪魔の角、落書き、強い斜め配置で不服従を攻撃的に見せない。マスコット素材は既存の「ぱっくん」を使用し、色・表情・ポーズを独自に変更して別の刺激にしない。

アイコンは同一系列のネイビー線画＋シアンのアクセントとする。企業の指示は書類、発言は吹き出し、比較は四分割、測定は質問票、分析はグラフを用いる。音声波形やロボットなど旧テーマ固有のモチーフは使用しない。実在ロゴを装飾目的で加えない。

## Voice & Content Strategy

文章は簡潔・客観的・探索範囲に忠実とする。本文は「検討する」「検証する」「予定である」を基本とし、調査前に「明らかになった」「効果がある」と書かない。見出しに短い問いを使ってよいが、本文で正式な概念と対応させる。

### 研究内容の固定点

| 論点 | 発表で維持する内容 |
|---|---|
| 不服従の定義 | 企業から明示された指示に意図的に従わない様子を描く広告表現 |
| 主要な評価対象 | ブランド「ポッケ」への態度。マスコットへの好意や購買意向と混同しない |
| Study1 | 刺激性／誠実性×従順／不服従の2×2参加者間計画 |
| 仮説1-1 | 刺激性ブランドでは、不服従表現は従順表現よりブランド態度に正の影響を与えるという予測 |
| RQ1-2 | 誠実性ブランドでの効果方向は限定しない。旧「負の仮説1-2」を復活させない |
| 交互作用 | ブランド像による効果差を検討。方向仮説は置かない |
| 割付 | 誕生月による便宜的な割付。厳密な無作為割付とは書かない |
| 主分析 | 交互作用とブランド像別の二つの計画比較。三検定は両側、Holm法で調整 |
| Study2 | 刺激性ブランド×不服従の一条件、Surveroid、有効回答100人を予定 |
| 測定22項目 | ブランド態度3＋印象18＋操作チェック1。同意・属性等を含む総画面数ではない |
| 因子分析 | 印象18項目のみ。ブランド態度・操作チェックは投入しない |
| 分析の位置づけ | 探索的因子分析と回帰分析による関連の検討。因果的媒介の証明とは呼ばない |
| 未確定事項 | Study1の標本数・募集方法、実施時期、最終刺激、プレ調査等は草案の状態を維持 |

### 発表用の文例

- 主問いの短縮表示：「不服従表現の効果は、ブランド像によって異なるか」。RQ1の正式文は草案から転記する。
- 仮説カード：「仮説1-1｜刺激性ブランドでは、不服従広告の方がブランド態度は高いと予測する」。必ず「予測」と表示する。
- 問いカード：「RQ1-2｜誠実性ブランドでは、どのような差が生じるか」。下降矢印を付けない。
- Study間の接続：「Study1で条件差を検討し、Study2で印象の構造とブランド態度との関連を探索する」。Study1で効果が確認されたことを前提にしない。
- まとめ：「ブランド像とマスコットの振る舞いを組み合わせて検討する」。効果を断定する宣伝コピーにしない。

「不服従」「期待からの逸脱」「ブランド像との不適合」は別の概念として記す。「適合感」を「真正性」と言い換えない。大胆さ・自由さ→ブランド像への適合→好意という説明を図示する場合は、破線と「想定する説明・媒介分析は行わない」の注記を付ける。

ひよこちゃんやDuoの事例は広い反抗・辞職演出の背景例であり、特定の明示的指示への違反やブランド態度への効果を実証した事例として描かない。出典は著者・年をスライド下部に記し、報道と原著論文を区別する。

## Components

### 条件マトリクス

| ブランド像 | 従順 | 不服従 |
|---|---|---|
| 刺激性 | A群：A指定→A採用 | B群：B指定→A採用 |
| 誠実性 | C群：A指定→A採用 | D群：B指定→A採用 |

条件のA〜DとコピーのA・Bは別の記号である。「A群」「コピーA」のように対象を省略しない。広告画像は二枚でもブランド紹介との組み合わせは四条件。性格を強調しない統制紹介はブランド像のプレ調査用であり、本調査の第五条件として追加しない。

### 刺激比較カード

両条件の完成広告の見出しは「今日のおやつに、ポッケ。」。不服従の現行発言は「会社の指示はわかった。でも、そのコピーは使わない。ぼくは、こっちでいくね。」とする。その他の文言は草案と現行画像を照合し、要約したセリフを実際の刺激として表示しない。

完成コピーの共通性とともに、指定コピー・拒否・自己主張の表現の違いが残ることを注記する。「不服従のみの純粋な効果」と説明しない。比較画像は同倍率、同じ枠、同じ余白で配置する。

### 測定カードと分析フロー

ブランド態度は「悪い—良い」「好ましくない—好ましい」「好きになれない—好きになれる」の三項目、7段階の両極形式を予定する。出典はSpears & Singh（2004）をもとにした改変であり、検証済み日本語版と表示しない。

Study2の分析フローは「印象18項目 → 探索的因子分析 → 因子の解釈・信頼性確認 → ブランド態度との回帰分析」とする。これは分析手順の矢印である。因子数・因子名・回帰係数を事前に確定表示しない。六つの候補観点を六因子と表記しない。

### 状態・出典・結果表示

「研究計画」「予定」「候補」「未取得」をstatus-chipで示す。数値の近くにも「有効回答100人予定」のように状態を併記する。結果未取得のページにはグラフや仮の有意差を置かず、分析計画を示す。実査後は実データと対応する出典・分析出力を確認して置き換える。

## Do's and Don'ts

### Do

- [ ] 白・ネイビー・シアンを基調にし、濃い文字と余白で読みやすさを確保する。
- [ ] 正確な16:9、同じ余白、一定の文字階層を使う。
- [ ] 一枚一メッセージとし、問い・仮説・計画・結果を区別する。
- [ ] 四条件、仮説1-1、RQ1-2、交互作用を草案の現行方針と照合する。
- [ ] Study2は一条件・100人予定・22項目、因子分析対象は18項目と確認する。
- [ ] 実験刺激は原画像を維持し、対等なサイズで比較する。
- [ ] 出典、日本語表記、はみ出し、画像内文字を実寸または投影想定で確認する。
- [ ] ページ番号を入れる場合は右下のみとする。

### Don't

- AI音声、広告信頼性、購買意向など、別テーマのモデルや例を流用しない。
- 不服従条件だけを派手にする、誠実性を地味にするなど、図の見た目で評価方向を誘導しない。
- 実測値のないグラフ、支持済みの仮説、固定された六因子、架空の係数を掲載しない。
- 一方の群が有意で他方が非有意という理由だけで、交互作用があると表現しない。
- Study2の関連を因果的な仕組みの証明としない。
- 装飾用の企業ロゴ、SNS画面の模倣、過度なグラデーション、小さな文字で情報を埋めない。
